## Запуск

Этот репозиторий — портфолио и описание системы, а не дистрибутив приложения.

1. Используйте [инструкцию развёртывания backend](https://github.com/Dmewtriy/hahaton/blob/master/docs/deployment.md).
2. Для подготовки ML-окружения см. [README ML](https://github.com/vit303/hakaton/blob/main/README.md).
3. Для соединения компонентов см. [local-rag.md](https://github.com/Dmewtriy/hahaton/blob/master/docs/local-rag.md).
4. Проверяйте работу реального ML отдельно от режима заглушки backend.

На дату проверки README ML содержит общие инструкции и шаблон вместо точной команды запуска. Точка HTTP-сервиса находится в `scripts/ml_service.py`; конкретное окружение, зависимости и доступность моделей необходимо проверить перед запуском. В рамках подготовки этого портфолио установка и GPU-тестирование не выполнялись.

## Авторство и материалы

Код компонентов остаётся в репозиториях команды с оригинальной историей. Корпоративные документы, секреты, базы данных и модели не входят в этот комплект. Условия использования исходного кода и моделей определяются их авторами и соответствующими лицензиями.
